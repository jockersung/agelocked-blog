# AGELOCKED｜ChatGPT 產圖作業手冊

搭配檔案：
- `AGELOCKED-ChatGPT產圖清單.xlsx`：全站 221 張圖，逐張列出要上傳什麼、要貼什麼訊息、存成什麼檔名。
- `IMAGE-STYLE.md`：風格規範（色碼、字型、尺寸、檢查清單）。
- `docs/style-anchors/`：風格錨點圖（一般 3 張、產品 4 張）。

---

## 一、一次性設定（約 15 分鐘）

### 1. 建立兩個 ChatGPT 專案

| 專案名稱 | 用途 | 上傳的專案檔案 |
|---|---|---|
| AGELOCKED 產圖 | 封面、機制圖、數據圖表 | `docs/style-anchors/` 的 3 張一般錨點圖，加上思源黑體字型檔 `NotoSansTC-Regular.ttf`、`NotoSansTC-Bold.ttf` |
| AGELOCKED 產品圖 | LifePak、R2、Meta、MyND360 等產品主視覺 | `docs/style-anchors/product/` 的 4 張產品錨點圖、各產品官方照片 |

字型檔可從 Google Fonts 下載 Noto Sans TC。數據圖表要靠它才能正確顯示中文。

### 2. 貼上專案指示

**「AGELOCKED 產圖」專案指示：**

```
你是 AGELOCKED 健康網站的插畫師。每次產圖都必須：
1. 以專案檔案中的 3 張錨點圖為風格參考，線條粗細、陰影、人物畫法、配色都和錨點圖一致。
2. 圖中不出現任何文字、字母、數字或 logo。需要標籤的位置畫空白的圓角標籤框。
3. 背景使用暖米白 #FAF7F2，不使用深色背景。
4. 一律產橫式圖片，主體放在畫面中央，四周留白。
5. 不畫寫實照片、3D、漫畫誇張臉、真實人物或品牌包裝。
6. 被要求畫數據圖表時，先讀出數據給我確認，確認後才用 Python 畫，字型使用專案檔案中的 NotoSansTC。
```

**「AGELOCKED 產品圖」專案指示：**

```
你是 AGELOCKED 的產品視覺設計師。每次產圖都必須：
1. 以專案檔案中對應產品的版面風格參考圖為準：左上標題區、左側功效圖示區、右側產品放在淺色圓台上、周圍是成分植物插畫、底部標語區。
2. 產品外觀、瓶蓋、標籤必須和我提供的官方產品照片完全一致，不改字、不改顏色。
3. 圖中不放任何文字，標題、圖示文字、標語的位置留空白，圓框圖示只畫線條圖案。
4. 一律產橫式圖片。
```

## 二、每天的產圖流程

**原則：一篇文章開一則新對話**，那篇的圖全部在同一則對話裡產完，下一篇再開新對話。這樣同一篇的圖風格會最一致，也不會越產越飄。

### 步驟

1. 打開清單，篩選「批次」，從批次 1 開始。
2. 同一個「文章 slug」的幾列一起做。
3. 依「類型」選專案：A、B、C 用「AGELOCKED 產圖」，D 用「AGELOCKED 產品圖」。
4. 依「要上傳的附件」上傳檔案。原圖在 repo 的「原檔／存放資料夾」欄位那個路徑。
5. 複製「貼給 ChatGPT 的訊息」整格貼上，送出。
6. 不滿意就用下方第四節的修改說法調整。
7. 滿意後下載，進 Canva 疊上「Canva 要填的文字」。C 類圖表不需要這一步。
8. 用「完成後存檔名」存成 PNG，放進原圖所在的文章資料夾**覆蓋原檔**。
9. 這篇的圖都放好後，執行轉檔（見第七節），PNG 會轉成 WebP，md 裡的路徑也會自動改好。
10. 在「完成」欄改成 ☑。

**存成原檔名的好處**：不用手動改任何 md，轉檔腳本會把路徑一起換成 `.webp`。

### 同一篇的第 2 張圖開始

在訊息最前面加一句：

```
風格和這則對話的第一張圖完全一致。
```

如果圖中有人物，也把第一張的人物圖附上，讓同一篇的人物長得一樣。

## 三、四種類型怎麼做

| 類型 | 清單裡的動作 | 你要做的事 |
|---|---|---|
| A 封面 | 新產／照原構圖重畫 | 貼訊息 → 下載 → Canva 疊一行短標 |
| B 機制圖 | 照原構圖重畫／換畫面重產／新產 | 貼訊息 → 下載 → Canva 依原圖文字填回標籤 |
| C 數據圖表 | ChatGPT 讀數據＋Python 重畫 | 貼訊息 → **核對 ChatGPT 讀出的數字** → 回覆「數據正確，請畫圖，資料來源是：○○」 → 下載 |
| D 產品圖 | 產品主視覺 | 上傳產品錨點＋官方產品照片 → 貼訊息 → **核對包裝文字** → Canva 疊文字 |

**C 類一定要核對數字**：ChatGPT 從圖片讀數字可能會讀錯。最好打開原始論文對照；資料來源寫在清單裡對應文章的參考文獻。

**D 類功效文字**：只能用產品在台灣核准的說法，不寫療效或疾病字眼。

## 四、常用修改說法

| 狀況 | 跟 ChatGPT 說 |
|---|---|
| 顏色跑掉 | 顏色改回錨點圖的青綠與琥珀，背景改回 #FAF7F2，其他不變。 |
| 出現文字 | 移除圖中所有文字和數字，其他不變。 |
| 太寫實 | 改成和錨點圖一樣的扁平向量畫法，不要光影質感。 |
| 主體太靠邊 | 主體移到畫面中央，四周留更多空白。 |
| 重畫後內容跑掉 | 構圖改回和原圖一致，只改畫風，元素數量和位置不要變。 |
| 產品包裝走樣 | 產品外觀改回和產品照片完全一致，包含標籤文字與瓶蓋顏色，其他不變。 |
| 圖表字變方塊 | 請使用專案檔案中的 NotoSansTC 字型重新輸出。 |

## 五、Canva 設定（做一次就好）

建立兩個模板：

| 模板 | 尺寸 | 內容 |
|---|---|---|
| 封面 | 2400 × 1260 | 放圖的框（填滿）＋一行標題文字框，思源黑體 Bold、96–120px、#1F2A30，位置固定在上方或左上 |
| 內文圖 | 2400 × 1350 | 放圖的框（填滿）＋標籤文字樣式：思源黑體 Medium、40px、#1F2A30 |

主體要放在中央 85% 寬、80% 高的範圍內，網站裁切成 2:1 時才不會切到。

**想省掉 Canva？** ChatGPT 也能直接把中文寫進圖裡，但常會有錯字或字形怪異，每張都要逐字校對，字型也無法統一。建議封面和產品圖一定走 Canva；內文機制圖如果標籤很少，可以試試讓 ChatGPT 直接寫，校對過再用。

## 六、建議進度

| 批次 | 內容 | 張數 | 建議時程 |
|---|---|---|---|
| 1 | 風格差異最大的圖、產品圖、論文圖表、真人畫面 | 37 | 第 1 週 |
| 2 | 新 9 篇文章的圖 | 28 | 第 2 週（配合文章上線） |
| 3 | 其餘封面重畫 | 52 | 第 3～4 週 |
| 4 | 其餘內文機制圖重畫 | 89 | 第 5～8 週 |
| 5 | 其餘數據圖表重畫 | 11 | 穿插進行 |
| — | 重複使用的同一張圖（光譜指數） | 4 | 批次 1 完成後直接複製 |

一天做 1～2 篇文章的圖（約 3～6 張），大約兩個月可以全站統一。

## 七、轉成 WebP 並放回網站

網站上的圖最終一律是 **WebP**。ChatGPT 下載的是 PNG，用 repo 裡的轉檔腳本處理：

1. 把完成的 PNG 放進 repo 對應的文章資料夾，覆蓋原檔。
2. 在 repo 根目錄執行：

```bash
npm run images:webp -- "src/content/blog/<分類>/<文章資料夾>"
```

   腳本會把資料夾裡的 PNG 轉成 WebP（最寬 2400px、品質 85），把 `index.md` 裡的 `.png` 路徑改成 `.webp`，再刪掉 PNG。不確定的話先加 `--dry` 預覽。一張 4MB 的 PNG 大約會變成 100KB。
3. commit 並推上 GitHub，Cloudflare Pages 會自動重新部署。

也可以把一批完成的 PNG 交給 Claude 的雲端工作階段，請它放進正確資料夾、執行轉檔，並開分支送 PR。

## 八、每張圖上架前的檢查

- [ ] 背景是米白，沒有深色底
- [ ] 圖上沒有 ChatGPT 產生的錯字；中文是 Canva 疊的思源黑體
- [ ] 橘紅只出現在發炎、警告或變差的地方
- [ ] 主體在安全區內
- [ ] 數據圖表的數字已對照原始論文，有寫資料來源
- [ ] 產品包裝和官方照片一致，功效文字是核准說法
- [ ] 存檔名和清單一致，已轉成 WebP，已在清單打勾
